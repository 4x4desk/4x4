# Security

If you find a security problem, please write to **security@4x4desk.app** rather than opening a public issue, so it can be fixed before it is widely known.

## What to include

- what the problem is, and what someone could do with it;
- the steps to see it, or a small example;
- the files or apps it touches, and the commit you looked at;
- whether, and how, you'd like to be credited.

## What happens next

This project is young and looked after by a small number of people, so it answers as soon as it can rather than to a set timetable. You'll hear back once the report has been read, and again when there is a fix. Please give us a fair chance to fix it before you share it.

## What is here

This repository holds the contracts, the shared parts and apps: plain HTML, CSS and JavaScript that run in the browser and fetch nothing from elsewhere. A problem in how an app handles what a person stores, or in a part every app uses, is very welcome.
