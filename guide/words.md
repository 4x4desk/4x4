# Words

Each word has one meaning, in what a person reads and in the code.

| Word | Means |
|---|---|
| **4x4 AWD Desk** | The full desk: a browser of its own, for Mac, Windows and Linux. "The desk" for short |
| **Levels** | The forms 4x4 comes in, each building on the last: the website, 2WD Desk, AWD Desk, 4x4 OS |
| **Zone** | A place on the screen that shows one thing at a time |
| **Dock** | A zone's own strip of icons; click one to bring that app to the front |
| **Splitter** | The line between two zones; drag it to resize |
| **Zen** | The zone you're working in fills the space; the others wait |
| **App** | Anything a person opens and uses in a zone. One folder |
| **Essence Application (EAP)** | 4x4's kind of app: a source, a website or our own page, plus our changes, cut down to what a person needs |
| **Recipe** | The file in an app's folder that holds our changes to its source |
| **Parts** | The shared stylesheet and module every app of ours is built from |
| **Workspace** | A named set of apps and the zones they sit in; nothing else |
| **Layer** | One of the five tiers the desk is built in, from the engine up to the person's data |
| **Foundation** | Layer 1: the browser engine, Firefox with our patches |
| **Contract** | A written promise between two layers: what one gives the other, not how either is built |
| **The look** | The one set of colours, sizes and type every surface uses, light and dark |
